## 📌 Project Overview
This project is part of my "Engagement Phase" at **DecodeLabs**. The goal was to transform a static layout into a living interface. Using JavaScript, I have created a "Nervous System" for the webpage that responds to user actions in real-time.

## 🎯 What I Implemented
* **Interactive Elements:** Buttons and toggles that react to user clicks.
* **Input-Process-Output (IPO) Loop:** Every button follows a logical flow—taking user input, processing it with JavaScript, and showing a visible output.
* **DOM Manipulation:** I used the Document Object Model (DOM) to update text and change themes (Light/Dark mode) dynamically.
* **Seamless UX:** The content updates instantly without needing to refresh the browser.

## 🛠️ Technical Skills Demonstrated
* **JavaScript Logic:** Wiring event listeners to specific page nodes.
* **Visual Mutations:** Using CSS classes and JS to change the look and feel of the site.
* **State Control:** Managing how information changes based on user selection.

## 📱 Interactive Features
* **Theme Switcher:** A button to toggle between professional Light and Dark modes.
* **Service Details:** Interactive buttons that reveal different information when clicked.
